# .github

Organisation-level defaults for [MelismaApp](https://github.com/MelismaApp).

- **`profile/README.md`** — the page shown on the organisation's front page. That is the only
  file here with a visible effect; GitHub renders it at github.com/MelismaApp and nowhere else.

Anything else added here (issue templates, a contributing guide, a code of conduct) applies to every
repository in the organisation that does not carry its own copy.

The app itself lives in **[melisma](https://github.com/MelismaApp/melisma)**.
